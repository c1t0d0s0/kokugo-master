# 国語マスター

小学 1〜6 年生が、学年に合わせた問題で国語の「ことばの力」をのばす Web アプリです。
サーバーは不要で、ビルドした静的ファイルを置くだけで動きます。

- 学年 (1〜6 年生) をえらぶと、その学年から 2 学年下までの問題が出る。URL に `?grade=3` を付けると 3 年生で開く
- **今日のチャレンジ**: 日本時間の日付と学年から、毎日ちがう 10 問 (できるだけ別々の単元から 1 問ずつ)。同じ日・同じ学年ならだれが開いても同じ問題。とちゅうでやめても、つづきから再開できる
- **単元の練習**: 16 の単元を何回でも練習できる (10 問ずつ、開くたびにちがう問題)。全問正解すると単元にはなまるがつく
- ポイントをためて、ヤマネコカード (20 種類) と交換する
- 記録はブラウザ (localStorage) に保存。Google でログインすると Firestore に保存され、ほかの端末でも同じ記録で遊べる
- `config.js` (または環境変数) に `GTM_ID` があれば、Google アナリティクス / タグマネージャーのタグを埋め込む

## 単元と問題の形

| 分野 | 単元 | 問題の形 |
|---|---|---|
| ことばの知識 | 慣用句 (712 問) | かるたの札で穴うめ (`karuta`) |
| | ことわざ・故事成語 | かるたの札で穴うめ (`karuta`) |
| | 四字熟語 | 意味をえらぶ (`choice`) |
| | 類義語・対義語 | 2 枚 1 組の札合わせ (`pair`)。まちがい 1 回までなら正解 |
| | 和語・漢語・外来語 | 使い分けをえらぶ (`choice`) |
| 文法・ことばのきまり | 主語・述語・修飾語 | 文の中の言葉をタップ (`pick`) |
| | 品詞 / こそあど言葉 / つなぎ言葉 / 敬語 | えらぶ (`choice` / `pick`) |
| 表記 | かなづかい・送りがな / かたかな | えらぶ (`choice`) |
| | ローマ字 | 読み書きの 4 択 (`choice`) と、タイルならべ (`order`) |
| | 句読点・かぎ | えらぶ / 「、」を入れる場所をタップ (`choice` / `pick`) |
| 言語文化 | 季語・俳句・短歌 | 季節当て (`choice`) と、五七五の組み立て (`order`) |
| | 昔の言葉・古文の入り口 | えらぶ (`choice`) |

問題は `src/data/units/*.ts` にあり、形は `src/core/types.ts` に書いてあります。

意味 (`meaning`) は一覧の文のまま (ふりがなだけ足してある) で、穴うめの場所・まちがいの札・学年・例文はこのアプリで足したものです。
まちがいの札は、入れても一覧のほかの慣用句にならないことを確かめてあります。

- 選択肢の問題は、**正解を `options[0]` に書く** (画面では毎回ならびかえる)
- `g` はいちばん合う学年。その学年から 2 学年上まで出題される
- 文の中で `漢字(かんじ)` と書くとふりがな、`［ ］` で強調、`＿＿` で空らん
- `npm test` の「問題データ」のテストで、id の重なり・正解の位置・ふりがなの書き方・学年ごとの問題数を確かめている

## ポイント・スタンプ・ヤマネコカード

- 今日のチャレンジ: 正解 1 問で 10pt、10 問全部正解でさらに 50pt (1 日 1 回分だけ。学年をかえたり、もう一度といたりしてもふえない)
- 今日のチャレンジを最後までやると、スタンプカードにスタンプ。7 日連続するたびに 500pt、その月が全部そろうと 3,000pt
- 練習ではポイントはもらえない
- カードは 40pt〜3,000pt の 20 枚 (合計 28,420pt)。毎日全問正解しても、全部そろうのに 2 か月以上かかる

ポイントの合計は保存せず、記録から毎回計算します (`src/core/rewards.ts`)。

## 設定 (config.js)

`config.example.js` をまねて、プロジェクト直下に `config.js` を置きます (git には入れません)。

```js
const GTM_ID = 'G-XXXXXXXXXX';            // G-… は Google アナリティクス、GTM-… はタグマネージャー
const FIREBASE_API_KEY = '…';             // 以下 4 つがそろうと Google ログインと Firestore への保存が有効になる
const FIREBASE_AUTH_DOMAIN = '….firebaseapp.com';
const FIREBASE_PROJECT_ID = '…';
const FIREBASE_APP_ID = '…';
```

同じ名前の環境変数があればそちらを優先します (GitHub Actions ではリポジトリの Variables に登録)。
どれもなければ、タグは埋め込まず、ログインの入り口も出しません (Firebase のコードも読みこまれません)。

## ログインと記録の保存 (Firebase)

- 画面はいつも手元 (localStorage) の記録を読み書きし、ログイン中は書きかわった分をまとめて Firestore に送る (`src/cloud/sync.ts`)
- ログインしたときは Firestore と手元の記録を合わせる (`src/core/merge.ts`。何回合わせても同じ結果になる)
- ログインなしの記録は `kokugo:v1:…`、ログイン中の人の写しは `kokugo:u:<uid>:…`。ログアウトすると写しは端末から消す
- ログインしたとき、端末にログインなしの記録があれば、アカウントにうつすかを聞く

Firestore の形は Wordlynx と共通で、`appId` は `kokugo-master` です。

```
users/{uid}                                   その人の情報 (名前・メールアドレスは保存しない)
users/{uid}/apps/kokugo-master                activeDays (スタンプ), completed (今日のチャレンジ daily-日付:正解数 と 練習のはなまる unit-単元-g学年),
                                              inventory (カード), settings (grade, sound)
users/{uid}/apps/kokugo-master/progress/{id}  今日のチャレンジの途中経過 (daily-日付-g学年)
```

Firebase の準備は Wordlynx の README と同じです (Authentication で Google を有効にし、`firestore.rules` をルールに設定)。
Wordlynx と同じ Firebase プロジェクトを使えば、1 つのアカウントで両方の記録を保存できます。
